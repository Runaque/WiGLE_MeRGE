# WiGLE_MeRGE

This tool runs in your browser and simplifies the workflow of uploading multiple .csv files by merging them into one file that takes a lot of work out of your hands!
How it works is extremely straightforward! Just drag and drop them, hit the "Merge" button, download and then upload to WiGLE.net.
