How it works
  1. The two header lines (WigleWifi-1.x,… and the column names) are taken from the first file.
  2. Every data row from every file is appended, in the order shown above (sorted by file name).
  3. Duplicate rows are kept. WiGLE handles repeated observations itself.
  4. Files that don't start with WigleWifi, or that use a different column layout than the first file, are skipped and marked in red.
  5. Upload the merged file at wigle.net → Uploads.
